## 🎯 About

**BigToolz** is a collection of **300+ free online tools** — all running in the browser, no signup, no installation, no hidden fees. Built with vanilla HTML, CSS, and JavaScript, it's blazing fast, mobile-friendly, and SEO-optimized.

### Why BigToolz?

- 🔒 **Privacy-first** — Most tools run 100% in your browser. Files never leave your device.
- ⚡ **Fast** — No bloated frameworks. Pure vanilla JS.
- 📱 **Mobile-friendly** — Works perfectly on any device.
- 🆓 **Free forever** — Supported by non-intrusive ads.
- 🔍 **SEO-optimized** — Built for search engines from day one.
- 📴 **PWA-ready** — Install as an app, works offline.

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| **Frontend** | HTML5, CSS3, Vanilla JavaScript (ES6+) |
| **Styling** | Custom CSS (no framework) |
| **Icons** | Inline SVG + Emoji |
| **Fonts** | Inter (Google Fonts, self-hosted) |
| **PDF** | pdf-lib, pdf.js |
| **Images** | Canvas API, JSZip |
| **PWA** | Service Worker + Manifest |

| **Analytics** | Google Analytics 4 |
| **Ads** | Google AdSense |
| **CMS (Blog)** | Markdown files |

> **No build step required.** Pure static site. Edit HTML/CSS/JS, push, done.
