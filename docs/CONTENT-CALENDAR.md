## 🎯 Content Strategy

### Purpose of the Blog

1. **Drive organic traffic** — Rank for long-tail keywords related to our tools
2. **Build topical authority** — Establish BigToolz as a tools/SEO/productivity expert
3. **Convert visitors** — Move blog readers to tool users
4. **Internal linking hub** — Strengthen SEO via cross-linking to tool pages
5. **AdSense revenue** — Increase page views for ad impressions

### Content Pillars

| Pillar | % of Content | Purpose |
|---|---|---|
| 🛠 **Tool Guides** | 30% | Explain how to use our tools, use cases |
| 📚 **How-To Tutorials** | 25% | Step-by-step guides for common tasks |
| 📈 **SEO & Marketing** | 20% | Rank higher, grow traffic |
| 💡 **Productivity Tips** | 15% | Work smarter, time-saving hacks |
| 📰 **Industry News** | 10% | Trends, updates, tool releases |

### Target Audience

- **Primary:** Freelancers, students, small business owners (age 20-45)
- **Secondary:** Designers, developers, content creators, marketers
- **Tertiary:** General internet users looking for quick solutions

## 🔄 Publishing Workflow

### Daily Routine (60-90 minutes)

**Step 1 — Outline (10 min)**
- Pick next topic from calendar
- Draft 5-7 H2 headings
- Note 3-5 internal links (tools + other posts)

**Step 2 — Draft (40 min)**
- Write in Markdown (see `/blog/posts/` format)
- 1,500-2,500 words
- Add real examples, not fluff

**Step 3 — Edit (15 min)**
- Read aloud for flow
- Fix grammar (Grammarly)
- Check facts

**Step 4 — Optimize (10 min)**
- Title tag: keyword in first 60 chars
- Meta description: 155 chars
- Primary keyword in H1, first paragraph, one H2
- Add alt text to images

**Step 5 — Publish (5 min)**

```bash
# Create new post
touch blog/posts/2026-01-16-how-to-compress-images.md

# Paste content
# Add images to blog/images/

# Commit & push
git add .
git commit -m "Add blog post: How to Compress Images"
git push

# Auto-deploy via GitHub Actions
```

### Weekly Tasks

- **Monday:** Review last week's posts for traffic
- **Wednesday:** Add 3-5 internal links from older posts
- **Friday:** Update one old post with new info
- **Sunday:** Plan next week's topics

### Monthly Tasks

- Review Search Console → add new queries to keywords
- Update best-performing posts (refresh + republish)
- Audit internal links
- Check broken links
- Update sitemap

## 🖼 Image Guidelines

### Where to Get Images

| Source | License | Cost |
|---|---|---|
| **Unsplash** | Free commercial | $0 |
| **Pexels** | Free commercial | $0 |
| **Pixabay** | Free commercial | $0 |
| **Screenshots** | Our own | — |
| **AI-generated** | Depends on tool | — |

### Image Optimization Rules

1. **Format:** WebP (fallback JPEG)
2. **Max size:** 100KB per image
3. **Max dimensions:** 1600px on longest side
4. **Naming:** `keyword-rich-filename.webp` (not `IMG_1234.jpg`)
5. **Alt text:** Describe image + include keyword naturally
6. **Featured image:** 1200×630 (OG standard)
7. **In-post images:** 800-1200px wide

### Tools to Optimize Images

- **BigToolz Image Compressor** — our own tool
- **Squoosh.app** — Google's free compressor
- **TinyPNG** — batch compression
