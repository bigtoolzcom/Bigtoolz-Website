🗺 What is a Sitemap.xml?

An XML sitemap is a file that lists every important URL on your website along with optional hints about when each page was last modified, how often it changes, and its relative importance within your site. Search engines like Google, Bing, and Yandex use sitemaps to discover new pages faster and understand the structure of your site.

A sitemap doesn't guarantee indexing or improve rankings directly, but it dramatically improves crawl efficiency especially for large sites, new sites, or sites with poor internal linking. Google recommends sitemaps for any site with more than 100 pages.

📏 Sitemap Limits & Rules

  • 50,000 URLs max per sitemap file.
  • 50 MB max uncompressed file size.
  • Only one URL per <url> entry.
  • Absolute URLs only full protocol and domain (https://example.com/page, not /page).
  • UTF-8 encoding required for all text.
  • Special characters must be XML-escaped (&, <, >, ', ").

🎯 Understanding Sitemap Fields

loc (Required)

The full URL of the page. Must include protocol and domain. Only ASCII characters allowed unless properly URL-encoded.

lastmod (Optional)

The last modification date in W3C Datetime format (e.g., 2026-01-15 or 2026-01-15T10:30:00+00:00). Google uses this to prioritize re-crawling recently updated pages.

changefreq (Optional)

How often the page changes: always, hourly, daily, weekly, monthly, yearly, never. Google now largely ignores this hint, but other engines may use it.

priority (Optional)

A number between 0.0 and 1.0 indicating the relative importance of this URL compared to others on your site. Default is 0.5. This does not affect ranking it only hints at crawl priority within your own site.
