⇄ What is CSS Flexbox?

      

        Flexbox (Flexible Box Layout) is a modern CSS layout model that makes it easy to arrange elements in a container horizontally or vertically with powerful alignment and spacing controls. It eliminates the need for floats, table-based layouts, or complex positioning hacks that were common before 2015.
      

      

        This interactive Flexbox playground lets you experiment with every property in real-time. Change a value, see the result instantly, and copy the generated CSS. Perfect for learning, prototyping, and debugging Flexbox layouts.

📚 Flexbox Properties Explained


      
Container Properties

      
flex-direction Sets the main axis. row (default, left-to-right), row-reverse, column (top-to-bottom), column-reverse.


      
flex-wrap Controls wrapping. nowrap (default, single line), wrap (multi-line), wrap-reverse (multi-line, cross-start at bottom).


      
justify-content Aligns items along the main axis. Values: flex-start, flex-end, center, space-between, space-around, space-evenly.


      
align-items Aligns items along the cross axis. Values: stretch (default), flex-start, flex-end, center, baseline.


      
align-content Aligns multi-line content along the cross axis (only when flex-wrap: wrap). Values similar to justify-content.


      
gap Space between items. Shorthand for row-gap and column-gap. Example: gap: 16px or gap: 8px 16px.


      
Item Properties

      
flex-grow How much an item grows relative to siblings. 0 (default) = don't grow. 1 = grow to fill available space.


      
flex-shrink How much an item shrinks when space is tight. 1 (default) = can shrink. 0 = won't shrink.


      
flex-basis Initial size before flex-grow/shrink. auto, 0, 100px, 30%, etc.


      
align-self Overrides container's align-items for a single item. Values: auto, flex-start, flex-end, center, stretch, baseline.


      
order Controls display order. Default 0. Lower numbers come first. Useful for reordering without changing HTML.


      
💡 Common Flexbox Recipes


      
Perfect Centering

      
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}


      
Navigation Bar

      
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}


      
Equal-Width Items

      
.item {
  flex: 1;
}
/* shorthand for flex-grow:1; flex-shrink:1; flex-basis:0; */


      
Card Grid with Wrapping

      
.grid {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
.card {
  flex: 1 1 250px; /* grow, shrink, basis 250px */
}


      
Sticky Footer Layout

      
body {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
main { flex: 1; } /* pushes footer to bottom */

❓ Frequently Asked Questions


      

        
        
Flexbox (Flexible Box Layout) is a CSS layout model designed for distributing space along a single axis. It makes it easy to align, space, and order elements in a container without using floats or complex positioning. Supported by all modern browsers.

      


      

        
        
justify-content aligns items along the main axis (horizontal if flex-direction is row). align-items aligns items along the cross axis (vertical if flex-direction is row).

      


      

        
        
Set the parent container to display: flex; justify-content: center; align-items: center;. This centers the child both horizontally and vertically no more negative margins or absolute positioning.

      


      

        
        
flex-grow = how much an item grows when there's extra space. flex-shrink = how much it shrinks when space is tight. flex-basis = its initial size before growing/shrinking. Shorthand: flex: 1 1 200px = grow=1, shrink=1, basis=200px.

      


      

        
        
Use Flexbox for one-dimensional layouts a row of cards, a navbar, a vertical stack. Use CSS Grid for two-dimensional layouts a full page with rows and columns, magazine-style layouts. They work great together.

      


      

        
        
Common reasons: (1) flex-shrink: 0 set on items, (2) min-width: auto on items with text content, (3) flex-basis too large. Try setting min-width: 0 on items or flex-wrap: wrap on the container.
