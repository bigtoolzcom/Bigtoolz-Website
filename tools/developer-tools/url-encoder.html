🔗 What is URL Encoding?

URL encoding (also called percent-encoding) converts characters that aren't allowed or have special meaning in URLs into a safe format. Each "unsafe" character is replaced with a % followed by two hex digits for example, a space becomes %20, & becomes %26, and non-ASCII characters like ü become multi-byte sequences like %C3%BC.

This is essential when building URLs dynamically user input, search queries, and form data all need encoding to avoid breaking the URL structure. Our tool runs 100% in your browser your data never leaves your device.

📐 Encoding Modes Explained

Component (encodeURIComponent)

Encodes every character with special meaning, including : / ? # [ ] @ ! $ & ' ( ) * + , ; =. Use this for individual values like one query parameter's value, or a filename.

Input Hello World! / café & tea? Output Hello%20World!%20%2F%20caf%C3%A9%20%26%20tea%3F

Full URL (encodeURI)

Preserves the structural characters of a URL (: / ? # & =), so the resulting URL is still usable. Use this when encoding a complete URL string.

Input https://example.com/search?q=hello world&lang=en Output https://example.com/search?q=hello%20world&lang=en

Query Param (form-safe)

Same as Component, but spaces become + instead of %20. This matches the older application/x-www-form-urlencoded standard used by HTML forms.

Input hello world & café Output hello+world+%26+caf%C3%A9

💡 Common Use Cases
