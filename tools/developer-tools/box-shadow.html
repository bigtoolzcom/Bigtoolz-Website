📐 Understanding box-shadow Syntax

CSS Syntax box-shadow: offset-x offset-y blur spread color inset; Example box-shadow: 0px 4px 12px 0px rgba(0,0,0,0.15);

Every parameter explained:

  • offset-x Horizontal shift. Positive = right, negative = left.
  • offset-y Vertical shift. Positive = down, negative = up.
  • blur Softness of edges. 0 = sharp, higher = softer.
  • spread Expands (positive) or shrinks (negative) the shadow.
  • color Shadow color, usually with alpha (rgba or hex + opacity).
  • inset Optional keyword for inner shadow.

💡 Box Shadow Best Practices

  • Use rgba or hsla for shadow colors full opacity black looks harsh; 5-20% opacity is usually ideal.
  • Blur ≈ 2× Y-offset for natural-looking shadows. Example: Y=8px, blur=16px.
  • Down shadows look natural the sun is above. Y should usually be positive.
  • Match the design system use consistent shadow scales (like shadow-sm, shadow-md, shadow-lg).
  • Layer two shadows one tight, one soft for realistic depth.
  • Animate transform, not box-shadow changing box-shadow on hover causes repaints; use transform: translateY instead.
