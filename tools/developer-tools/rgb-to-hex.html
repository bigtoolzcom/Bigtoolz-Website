#FF What is RGB to HEX Conversion?

RGB to HEX conversion transforms a color expressed in Red-Green-Blue values (each 0-255) into a HEX code (like #FF5733) used in HTML, CSS, and design tools. Both formats describe the exact same color HEX is just a compact, base-16 representation that's easier to copy-paste into code.

📐 The Conversion Formula

RGB → HEX

Convert each channel (R, G, B) from decimal (0-255) to hexadecimal (00-FF). Then concatenate with a # prefix.

255 → FF (red)
87 → 57 (green)
51 → 33 (blue)

Result: #FF5733

HEX → RGB

Split the HEX into pairs, convert each pair from base-16 to decimal.

#FF5733

FF → 255
57 → 87
33 → 51

Result: rgb(255, 87, 51)

💡 Common Color Examples

  • Red: rgb(255, 0, 0) = #FF0000
  • Green: rgb(0, 255, 0) = #00FF00
  • Blue: rgb(0, 0, 255) = #0000FF
  • White: rgb(255, 255, 255) = #FFFFFF
  • Black: rgb(0, 0, 0) = #000000
  • Orange: rgb(255, 165, 0) = #FFA500
