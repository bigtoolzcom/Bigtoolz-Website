▦ What is CSS Grid?

CSS Grid is a two-dimensional layout system built into every modern browser. Unlike flexbox (which is primarily 1D), Grid lets you define both rows and columns and place items anywhere on the grid with precise control. It's the recommended tool for full-page layouts, dashboards, galleries, and magazine-style designs.

This CSS Grid Generator lets you build layouts visually and copy production-ready CSS. No manual coding, no guesswork just click, adjust, and paste into your project.

📐 CSS Grid Units Explained

fr (Fraction)

The fr unit represents a fraction of the free space. In grid-template-columns: 1fr 2fr, the second column is twice as wide as the first. This is the most common unit for responsive layouts.

px (Pixels)

Fixed size. Use for sidebars, toolbars, or elements that shouldn't grow/shrink. Example: 200px 1fr sidebar + flexible content.

% (Percentage)

Percentage of the container width. Works but fr is often better because it accounts for gaps automatically.

auto

Sizes based on content. The track will be as wide as its widest child. Great for navigation or buttons.

min-content / max-content

min-content smallest size that fits content without breaking. max-content largest natural size without wrapping.

💡 Common Grid Patterns

Holy Grail Layout

.grid {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header header"
    "nav main aside"
    "footer footer footer";
}

Responsive Gallery (No Media Queries)

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 16px;
}

Dashboard Layout

.grid {
  display: grid;
  grid-template-columns: 250px 1fr 1fr;
  grid-template-rows: 60px 1fr 1fr;
  gap: 16px;
}
