<{>} What is XML to JSON Conversion?

XML to JSON conversion transforms data from Extensible Markup Language (XML) the classic, tag-based format used in SOAP APIs, RSS feeds, configuration files, and legacy systems into JavaScript Object Notation (JSON) the modern, lightweight format used by virtually every REST API, JavaScript application, and NoSQL database today.

Unlike most online tools, BigToolz processes data 100% in your browser using the native DOMParser API. Your XML never uploaded to any server perfect for API responses, config files, or sensitive enterprise data.

📐 Conversion Rules

Basic Elements

XML <root> <name>John</name> <age>30</age> </root>
JSON { "root": { "name": "John", "age": 30 } }

Attributes → @ Keys

XML <user id="1" role="admin"> <name>John</name> </user>
JSON (with @ prefix) { "user": { "@id": 1, "@role": "admin", "name": "John" } }

Repeated Elements → Arrays

XML <colors> <item>red</item> <item>green</item> <item>blue</item> </colors>
JSON (auto array detection) { "colors": { "item": ["red", "green", "blue"] } }

Mixed Content → #text

XML <note priority="high">Call back tomorrow</note>
JSON { "note": { "@priority": "high", "#text": "Call back tomorrow" } }

By default, XML attributes become JSON keys prefixed with @. For example, <user id="1">John</user> becomes {"user": {"@id": "1", "#text": "John"}}. You can customize the prefix in settings.

When multiple sibling elements have the same tag name, they're combined into a JSON array. For example, three <item> tags become a single "item": [...] array. Toggle "Auto-detect arrays" to control this behavior.

Elements with both attributes and text content use the #text key. For example, <note priority="high">Hello</note> becomes {"note": {"@priority": "high", "#text": "Hello"}}.
