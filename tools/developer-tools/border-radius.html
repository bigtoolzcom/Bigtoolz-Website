▢ What is CSS border-radius?

border-radius is a CSS property that rounds the corners of an element. It's one of the most-used modern CSS properties every card, button, avatar, and modal you see on the web today uses it. It accepts one to four values (one per corner) and can also take elliptical values (horizontal radius / vertical radius) for oval-shaped corners.

Our Border Radius Generator gives you a live visual editor to design the perfect rounded corner, then copy production-ready code in CSS, HTML, JSX, or Tailwind format. Runs 100% in your browser.

📐 border-radius Syntax

1 Value (all corners)

.box { border-radius: 16px; }
/* All 4 corners get 16px */

2 Values (opposite corners)

.box { border-radius: 16px 40px; }
/* TL + BR = 16px, TR + BL = 40px */

3 Values

.box { border-radius: 16px 32px 8px; }
/* TL = 16, TR + BL = 32, BR = 8 */

4 Values (each corner)

.box { border-radius: 16px 32px 8px 0; }
/* Order: TL, TR, BR, BL (clockwise) */

Elliptical (horizontal / vertical)

.box { border-radius: 50px / 25px; }
/* H radius 50px, V radius 25px oval corners */

💡 Common Shapes & Recipes

  • Perfect Circle: border-radius: 50% on a square element.
  • Pill / Capsule: border-radius: 9999px (works on any width).
  • Avatar: border-radius: 50% + overflow: hidden for images.
  • Squircle (iOS-style): Use large border-radius with mild % mixing.
  • Blob / Organic: Use distinct per-corner values like 60% 40% 30% 70% / 60% 30% 70% 40%.
  • Leaf / Petal: border-radius: 0 100% 0 100% diagonal shapes.
