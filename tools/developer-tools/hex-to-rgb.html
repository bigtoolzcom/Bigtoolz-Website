#→RGB What is HEX to RGB Conversion?

HEX to RGB conversion translates a hexadecimal color code (like #FF5733) into its RGB equivalent (rgb(255, 87, 51)). Both represent the same color HEX is just a compact base-16 notation used in CSS, HTML, and design tools, while RGB breaks the color into red, green, and blue channels (0-255 each).

📐 Understanding Color Formats

HEX (#RRGGBB)

Base-16 representation. Each pair represents red, green, blue from 00 to FF. Example: #FF5733 → FF (red=255), 57 (green=87), 33 (blue=51). Best for web (CSS/HTML).

RGB (r, g, b)

Three channels from 0-255. Same information as HEX, just in decimal. rgb(255, 87, 51) = #FF5733. Best when working with code that does math on channels.

HSL (h, s%, l%)

Hue (0-360°), Saturation (0-100%), Lightness (0-100%). Most intuitive for designers easy to make "lighter" or "more saturated" versions.

HSV (h, s%, v%)

Similar to HSL but uses Value (brightness) instead of Lightness. Used by color pickers in most software (Photoshop, Figma).

CMYK (c%, m%, y%, k%)

Subtractive color for print. Cyan, Magenta, Yellow, Key (black). Screens use RGB (additive), printers use CMYK (subtractive) that's why printed colors can look different.

💡 Common HEX ↔ RGB Examples

  • #000000 → rgb(0, 0, 0) Black
  • #FFFFFF → rgb(255, 255, 255) White
  • #FF0000 → rgb(255, 0, 0) Red
  • #00FF00 → rgb(0, 255, 0) Green
  • #0000FF → rgb(0, 0, 255) Blue
  • #FF5733 → rgb(255, 87, 51) Orange
  • #3B82F6 → rgb(59, 130, 246) Tailwind Blue-500
  • #8B5CF6 → rgb(139, 92, 246) Violet
