🤖 What is robots.txt?

robots.txt is a plain text file placed at the root of a website (example.com/robots.txt) that tells search engine crawlers which pages they may or may not crawl. It's the very first thing Googlebot, Bingbot, and other crawlers request when visiting your site. The file uses the Robots Exclusion Protocol a simple standard supported by all major search engines.

Every website should have a robots.txt file, even if it just says "allow everything." Without one, crawlers see a 404 error and typically default to allowing everything which usually works, but gives you no control over what gets crawled. A proper robots.txt protects admin panels, prevents duplicate content, and points crawlers to your sitemap.

📝 Basic robots.txt Syntax

A robots.txt file uses four main directives:

# Comments start with a hash User-agent: * Allow: / Disallow: /admin/ Disallow: /private/ Crawl-delay: 1 Sitemap: https://example.com/sitemap.xml

User-agent

Specifies which crawler the rules apply to. * means all crawlers. You can target specific bots like Googlebot, Bingbot, GPTBot, etc.

Allow / Disallow

Tell crawlers which paths they may or may not access. Disallow: /admin/ blocks the entire admin directory. Allow: / permits everything.

Crawl-delay

Requests crawlers wait N seconds between requests. Google ignores this directive, but Bing and Yandex respect it. Use only if your server is overwhelmed by crawlers.

Sitemap

Points crawlers to your XML sitemap. Not a standard robots.txt directive, but universally supported and highly recommended.

💡 Best Practices

  • Always include a sitemap URL it helps crawlers find all your pages.
  • Block admin, cart, search, and checkout pages they waste crawl budget.
  • Use trailing slashes for directories (/admin/ not /admin).
  • Test before uploading use Google Search Console's robots.txt tester.
  • Don't disallow CSS/JS Google needs them to render your pages properly.
  • Remember: robots.txt ≠ noindex. Blocked pages can still be indexed if linked.
  • Keep it simple a clean robots.txt is easier to maintain and debug.
