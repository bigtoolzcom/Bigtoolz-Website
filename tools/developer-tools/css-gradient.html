🌈 What is a CSS Gradient?

A CSS gradient is a smooth color transition applied as a background using pure CSS no images needed. Gradients are defined with the linear-gradient() or radial-gradient() functions and can be applied to any element's background, text, or border. They're essential for modern web design used in hero sections, buttons, cards, text effects, and more.

📐 Linear vs Radial Gradients

Linear Gradient

Colors transition along a straight line. You control the angle 0° points up, 90° points right, 180° points down, 270° points left. Common angles: 45deg (bottom-left to top-right), 135deg (top-left to bottom-right).

Linear Gradient CSS background: linear-gradient(135deg, #667eea, #764ba2);

Radial Gradient

Colors radiate outward from a center point in a circle or ellipse shape. You can position the center anywhere using keywords like center, top left, or bottom right.

Radial Gradient CSS background: radial-gradient(circle at center, #f093fb, #f5576c);

💡 Pro Tips

  • Text gradients: Add -webkit-background-clip: text; -webkit-text-fill-color: transparent; after applying gradient to text.
  • Smooth transitions: Use adjacent hues (like blue → purple) for elegant gradients.
  • Add mid-stops: For richer effects, add 3-4 stops instead of just 2.
  • Match brand colors: Use your brand's HEX codes for on-brand UI.
  • Animated gradients: Combine with @keyframes and background-position for movement.
