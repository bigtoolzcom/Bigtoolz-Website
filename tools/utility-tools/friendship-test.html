🤝 What is a Friendship Test?

A Friendship Test is a fun online calculator that gives a "compatibility score" between two friends based on their names. It's a lighthearted game popular among school kids, college friends, couples, and anyone looking to share a laugh. You enter two names, hit the button, and get an instant score with a fun verdict.

Our tool uses a deterministic algorithm meaning the same two names always give the same result. This makes it consistent, shareable, and honest. Unlike other sites that generate random scores every time, ours is fair: your friend will get the exact same score when you share the link.

💡 How the Algorithm Works

Our friendship test uses a deterministic hash-based algorithm:

  • Each letter of both names is converted into a number (A=1, B=2, etc.)
  • The letters are combined into a single hash value
  • The hash is mapped to a score between 0 and 100
  • Special bonuses for matching first letters, matching lengths, or rhyming patterns
  • The result is consistent same names, same score, always

Remember: this is a fun game. The score has no scientific basis. Real friendship is built on trust, time, shared experiences, and mutual respect none of which can be measured by letters in names.
