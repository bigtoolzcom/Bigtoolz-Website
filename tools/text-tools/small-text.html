⚙️ How Superscript and Subscript Work

Superscript text appears slightly above the normal baseline like the "2" in "x²". In Unicode, letters like ᵃ ᵇ ᶜ ᵈ exist as separate characters from the normal a b c d.

Subscript text appears below the baseline like the "2" in "H₂O". Unicode provides characters like ₐ ₑ ₕ ᵢ for this purpose.

Since these are real Unicode characters, they work in any text field no font installation needed. They do reduce readability slightly, so use them for short text and effect not paragraphs.
