What is Morse Code?

Morse code is a method of encoding text using sequences of dots (.) and dashes (-). Each letter, digit, and punctuation mark has a unique pattern. It was widely used in telegraphy and radio communication before modern digital systems, and remains popular among amateur radio operators, hobbyists, and for emergency signaling.

🔊 Timing Rules of Morse Code

Morse code has strict timing rules based on the dot as the base unit:

  • Dot: 1 unit
  • Dash: 3 units
  • Gap between dots/dashes in a letter: 1 unit
  • Gap between letters: 3 units
  • Gap between words: 7 units

At 20 WPM, one unit ≈ 60 milliseconds. Our audio player uses these exact timings for authentic playback.
