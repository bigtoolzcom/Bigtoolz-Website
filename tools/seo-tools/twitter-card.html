𝕏 What is a Twitter Card?

A Twitter Card is a rich media preview that appears when a link is shared on X/Twitter. Instead of a plain URL, the card displays an image, title, description, and domain making the tweet more engaging, professional, and clickable.

Twitter Cards are built with <meta name="twitter:..."> tags placed in the <head> of your HTML page. If Twitter-specific tags are missing, X/Twitter falls back to Open Graph (og:) tags but including both gives the best preview control.

📋 Essential Twitter Card Tags

  • twitter:card Card type (required)
  • twitter:title Title shown on card (70 chars optimal)
  • twitter:description Description (200 chars optimal)
  • twitter:image Full URL to preview image
  • twitter:image:alt Alt text for accessibility
  • twitter:site Website's @handle
  • twitter:creator Content author's @handle

💡 Best Practices

  • Use summary_large_image for 95% of content it gets 2-3x more engagement than small thumbnails.
  • Image ratio: 1.91:1 works best (1200×628 is the sweet spot).
  • Image size: Keep under 5MB, JPG or PNG preferred.
  • Test before publishing use the Twitter Card Validator at cards-dev.twitter.com/validator.
  • Combine with Open Graph include both og: and twitter: tags for maximum reach.
  • Use HTTPS image URLs HTTP images won't display.
  • Keep titles under 70 chars longer titles get truncated.
  • Write compelling descriptions cards with good descriptions get 25%+ more clicks.
