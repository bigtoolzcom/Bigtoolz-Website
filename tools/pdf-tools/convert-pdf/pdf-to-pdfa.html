📚 What is PDF/A?

PDF/A is an ISO-standardized version of PDF (ISO 19005) specifically designed for long-term digital preservation. Unlike regular PDFs, PDF/A files are self-contained they embed all fonts, use only standard color spaces, disable external dependencies, and include mandatory XMP metadata. The result: a document that will display identically for decades, regardless of future software or system changes.

Unlike most online PDF/A converters, BigToolz processes everything 100% in your browser using pdf.js and pdf-lib. Your PDF never uploaded to any server complete privacy, instant results.

📌 PDF/A Versions Explained

  • PDF/A-1b (ISO 19005-1, Level B): Basic conformance. Requires font embedding and standard color spaces. Broadest legacy support. Doesn't support transparency.
  • PDF/A-2b (ISO 19005-2, Level B): Recommended for most uses. Adds support for JPEG2000, transparency, layers, and PDF/A-1 compatibility. Widely accepted by modern archival systems.
