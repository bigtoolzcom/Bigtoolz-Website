🚫 What is Crop Mark Removal?

Crop mark removal cleans up PDFs by hiding the small trim marks printed at the corners for cutting. This is useful when you want to:

  • Repurpose a print-ready PDF as a screen document (ebook, email attachment).
  • View or print without the mark distraction.
  • Clean up client deliverables that shouldn't show printer marks.
  • Prepare PDFs for publishing platforms that don't want printer marks.

Unlike most online tools, BigToolz processes everything 100% in your browser using pdf-lib. Your PDF never uploaded to any server complete privacy.

🎯 How Detection Works

1. Page Box Analysis

PDF pages have multiple boxes:

  • MediaBox the largest area (includes bleed + marks).
  • CropBox the visible area (often equals MediaBox).
  • BleedBox the area for bleed.
  • TrimBox the final trim size.

If CropBox is bigger than TrimBox, there's usually marks in the difference. Our tool detects this and adjusts CropBox to match TrimBox (or a user-defined smaller area).

2. Content Boundary Detection

Even without TrimBox metadata, we can estimate where content ends usually 15-25 pt inside the page edge on print-ready PDFs. The default 20 pt crop is based on industry standards.

3. Manual Override

If auto-detection doesn't fit, use the manual crop box adjust sliders to set exact top/bottom/left/right crop values in points. This gives you pixel-perfect control.

📐 Recommended Crop Values

  • Standard crop marks: 20 pt (about 7 mm) each side.
  • With 3 mm bleed: 28 pt (7.9 mm) total offset.
  • With 5 mm bleed: 34 pt (9.6 mm) total offset.
  • Aggressive (marks only): 15 pt (5.3 mm) each side.
  • Conservative (keep some margin): 25 pt (8.8 mm) each side.
