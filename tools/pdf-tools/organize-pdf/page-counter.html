🔢 What is a PDF Page Counter?

A PDF page counter tells you how many pages a PDF file contains instantly. Beyond just counting, our tool also shows file size, PDF version, metadata (title, author, subject, keywords, creator, producer, dates), page dimensions, orientation, and thumbnail previews.

Unlike most online tools, BigToolz processes everything 100% in your browser using pdf.js the same engine Mozilla Firefox uses to display PDFs. Your PDF never uploaded to any server complete privacy, instant results.

📄 File Details

  • File name original filename.
  • File size formatted in B/KB/MB.
  • PDF version 1.4, 1.5, 1.6, 1.7, or 2.0.

ℹ️ PDF Metadata

  • Title document title (if set).
  • Author creator name.
  • Subject short description.
  • Keywords search keywords.
  • Creator original application (e.g. Word, InDesign).
  • Producer PDF export library (e.g. Adobe PDF Library).
  • Created / Modified timestamps.

📐 Page Dimensions

See the exact size of each page in both points (PDF units) and millimeters (real-world dimensions). Orientation (portrait/landscape) is detected automatically.

🖼 Page Previews

Visual thumbnails of the first 12 pages helpful for quickly identifying what's in the PDF without opening it.
