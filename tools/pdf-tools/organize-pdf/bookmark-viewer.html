🔖 What is a PDF Bookmark Viewer?

A PDF bookmark viewer (also called PDF outline viewer) shows the navigational table of contents embedded inside a PDF file. Bookmarks let readers jump to specific sections instantly like chapter links in an ebook. Many PDFs (books, manuals, reports, research papers) include these bookmarks, but most PDF readers hide them or make them hard to inspect.

Our tool displays the full hierarchical outline tree in an easy-to-read sidebar. Click any bookmark to jump to its page with live preview. You can also export the entire bookmark structure as JSON or plain text great for indexing, migrating, or analyzing documents.

🎯 What Are PDF Bookmarks?

PDF bookmarks (formally called "outline" in the PDF spec) are a hierarchical list of navigational links stored in the PDF. Each bookmark has:

  • Title the visible label (e.g. "Chapter 1: Introduction").
  • Destination a specific page (and optionally position).
  • Hierarchy bookmarks can nest, creating sub-sections.
  • Color & style optional bold/italic formatting.

When present, bookmarks appear in PDF readers (Adobe, Firefox, Chrome, etc.) as a sidebar panel. But not all readers show them and even when they do, extracting the structure for analysis or migration isn't easy. That's where this tool helps.
