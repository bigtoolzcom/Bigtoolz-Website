💧 What is Watermark PDF?

Watermark PDF adds a text overlay (like "CONFIDENTIAL", "DRAFT", or "© Your Name") to every page of a PDF. It's used for protecting sensitive documents, marking drafts before publication, claiming ownership, or branding documents you share publicly.

Unlike most online tools, BigToolz processes everything 100% in your browser using pdf-lib. Your PDF never uploaded to any server complete privacy, instant results. Watermarks are added as vector text overlays, so original content stays 100% untouched.

📐 Watermark Positioning Guide

Diagonal (Most Common)

Set position to Center with rotation 45°. The watermark runs corner-to-corner, is hard to crop out, and looks professional. Use opacity 15-30% for subtle, 40-60% for prominent.

Straight Footer/Header

Set position to Bottom-Center or Top-Center with rotation 0°. Perfect for adding "© Company Name" or "Draft" as a subtle footer/header without obstructing the content.

Tiled (Maximum Protection)

Enable Tile Watermark the watermark repeats in a grid across the page. Best for "COPY" or "SAMPLE" stamps on previews. Use lower opacity (10-20%) so multiple watermarks don't overwhelm the content.

Corner Brand Mark

Set position to any corner (top-left, bottom-right, etc.) with small font size (20-30pt) and opacity 30-40%. Works like a logo overlay without disrupting the page.

💡 Recommended Settings

  • "CONFIDENTIAL": Center, 45° rotation, red (#FF0000), 20-30% opacity, font 60-80pt.
  • "DRAFT": Center, 45° rotation, gray (#888888), 15-25% opacity, font 80-100pt.
  • "© Your Name 2026": Bottom-center, 0° rotation, gray, 25% opacity, font 10-14pt.
  • "SAMPLE": Tile mode, 30° rotation, red, 10% opacity, font 30-40pt.
  • Logo-style branding: Corner position, 0° rotation, brand color, 40% opacity, font 20-30pt.
