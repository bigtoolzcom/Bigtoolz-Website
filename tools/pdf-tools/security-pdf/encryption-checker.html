    🔍 What This Tool Detects

    1. Encryption Type

    PDFs use different encryption algorithms. This tool identifies which one your file uses:

    • None The PDF is not encrypted. Anyone can open, copy, and edit it.
    • RC4-40 Outdated 40-bit encryption. Very weak by modern standards.
    • RC4-128 128-bit RC4. Also outdated; consider re-encrypting with AES.
    • AES-128 Strong 128-bit AES. Standard for many applications.
    • AES-256 Strongest available. Used by modern PDFs and Acrobat.

    2. Password Protection

    PDFs can have two types of passwords:

    • User (Open) Password Required to open the PDF at all. Without it, the file is unreadable.
    • Owner (Permissions) Password Restricts printing/copying/editing but doesn't prevent opening. Anyone can view the file, but not perform restricted actions.

    3. Permissions

    Even without a password, PDFs can restrict what users can do. This tool checks:

    • Printing Can the PDF be printed? (None / Low-res / Full)
    • Copying Can text and images be copied?
    • Modifying Can content be edited?
    • Annotating Can comments/notes be added?
    • Form Filling Can form fields be filled?
    • Page Extraction Can pages be extracted?

    📊 Security Grades Explained

    • 🟢 Excellent AES-256 encryption with strong password protection.
    • 🟢 Good AES-128 with password protection and appropriate permissions.
    • 🟡 Moderate Encrypted but with weak algorithm (RC4-128) or no password.
    • 🔴 Weak RC4-40 or restricted permissions only, no encryption.
    • ⚫ None No encryption at all. File is fully accessible.
