    ℹ️ What is PDF Metadata?

    PDF metadata is information about a document, embedded inside the PDF file itself. It includes things like the title (what shows up in browser tabs and file managers), the author, a subject summary, keywords, and which app created or produced the file. It also includes timestamp information (created/modified dates).

    Unlike most online tools, BigToolz processes everything 100% in your browser using pdf-lib. Your PDF never uploaded to any server complete privacy, instant results. Editing metadata doesn't touch the page content only the properties are changed.

    📝 Metadata Fields Explained

    Title

    The document's display name. Browsers, file managers, and PDF readers show this in tabs and window titles. If empty, they typically fall back to the filename. Most common field to fix.

    Author

    Typically the person or organization that authored the content. Not tied to the PDF's technical creator it's a user-defined attribution.

    Subject

    A one-line summary or description of the document. Often used by document management systems for classification.

    Keywords

    A comma-separated list of terms. Search tools and some PDF readers use these for indexing. Keep them relevant and short.

    Creator

    The application that created the original content before PDF conversion (e.g., "Microsoft Word", "Google Docs").

    Producer

    The application that produced the PDF itself (e.g., "Adobe Acrobat", "Skia/PDF"). Often indicates which tool made the final PDF.
