ℹ️ What is PDF Metadata?

PDF metadata is descriptive information stored inside every PDF file. Unlike the visible content, metadata lives in the file's Document Information Dictionary and doesn't show up when printed. It typically includes:

  • Title the name of the document.
  • Author who created it.
  • Subject a brief description.
  • Keywords search terms.
  • Creator the software used to create it (e.g. Word, LibreOffice).
  • Producer the software that generated the PDF (e.g. Adobe, Ghostscript).
  • Creation Date and Modification Date.

Metadata is used by search engines, PDF viewers, digital libraries, and file organizers. It's also a privacy concern authors often don't realize how much personal info leaks into PDF metadata.

🔒 Privacy & Security Concerns

PDF metadata often contains more information than you'd expect. Before sharing a PDF publicly or posting it online, check for these common leaks:

  • Full name of the author often your real name or company email.
  • Organization name visible in the Creator field if you used a licensed Word/Office.
  • Original file path the local path where the file was saved (sometimes includes your username).
  • Software versions reveal your OS and editing tools.
  • Comments or tracked changes some PDFs retain reviewer info.
  • GPS coordinates for photos embedded in PDFs.
