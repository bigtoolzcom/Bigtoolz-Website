📊 What is Split PDF by Size?

Split PDF by Size breaks a large PDF into multiple smaller files, each staying under a target size you specify (e.g., 5 MB, 10 MB, 25 MB). Unlike splitting by page count, this tool focuses on the file size limit essential when you're uploading to platforms with size restrictions, sending email attachments, or archiving to storage with constraints.

Unlike most online tools, BigToolz runs 100% in your browser using pdf-lib. Your PDFs never uploaded to any server complete privacy, instant results, no file size limits on the source.

🔬 How Size-Based Splitting Works

We don't just split by page count we estimate each page's file size and group them intelligently:

  1. Load the source PDF read all pages into memory.
  2. Estimate per-page size divided by average based on page complexity.
  3. Greedy grouping add pages to a chunk until it approaches the target cap (~90%).
  4. Rebuild each chunk copy the pages into a fresh PDF with pdf-lib.
  5. Verify sizes check each output blob; if any exceeds the cap, redistribute.

The result: evenly-sized chunks that all fit under your limit, with no page left behind.

📐 Understanding PDF Size Overhead

PDFs contain more than just page content they include fonts, images, metadata, bookmarks, and structure data. When you split a PDF, each output file gets its own copy of shared resources, which adds a small overhead (usually 1-10%).

That's why we use ~90% of your target size as the actual cap during splitting. This ensures every output file stays under the limit even after overhead is added.
