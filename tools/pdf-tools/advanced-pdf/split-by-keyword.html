🔍 What is Split PDF by Keyword?

Split PDF by keyword divides a single PDF into multiple separate PDFs splitting at pages that contain a specific word or phrase. This is perfect for documents with chapter headings, section markers, or repeating titles. Instead of manually finding boundaries, our tool does it automatically.

Unlike most online tools, BigToolz runs 100% in your browser using PDF.js and pdf-lib. Your PDFs never uploaded to any server complete privacy, instant results, no file size limits.

🎯 The 3 Split Modes Explained

⬅️ Split Before Keyword

The page containing the keyword becomes the first page of the next segment. This is the most common mode for chapter splitting "Chapter 2" page starts segment 2, and everything before stays in segment 1.

Example: Page 5 has "Chapter 2". Segment 1 = pages 1-4. Segment 2 = pages 5+.

➡️ Split After Keyword

The page containing the keyword stays in the current segment. The next page starts the new segment. Useful when the keyword is a "concluding" marker.

Example: Page 5 has "End of Chapter 2". Segment 1 = pages 1-5. Segment 2 = pages 6+.

🎯 Split On Keyword

Similar to "Before" the keyword page opens the new segment. This is useful for section markers where the section heading starts the segment.

💡 Common Use Cases

  • Book chapters split a book PDF into individual chapter PDFs.
  • Course materials separate lessons by "Lesson 1", "Lesson 2", etc.
  • Legal documents split contracts by "Section 1", "Section 2".
  • Reports divide a report by "Executive Summary", "Introduction", etc.
  • Multi-invoices split a batch PDF by "Invoice #".
  • Meeting minutes split by "Meeting Date:".

💡 Best Practices

  • Choose distinctive keywords. "Chapter" is common and works. "The" is too broad.
  • Test with preview first. The segments list shows you what will be created before downloading.
  • Use partial match for variants. "Chapter" matches "Chapters", "Chapter 1", etc.
  • Multiple keywords: Use comma to split at any of them. "Chapter,Part,Section" splits at all three.
  • Case sensitivity: Leave ON unless your document has unusual capitalization patterns.
  • Page range: Limit search to skip front matter (like a cover page).
