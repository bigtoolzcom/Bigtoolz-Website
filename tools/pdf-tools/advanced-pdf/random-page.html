🎲 What is a PDF Random Page Picker?

A random page picker selects random pages from a PDF and lets you download them as a new document. It's useful for random sampling for research, creating surprise quizzes from textbooks, previewing arbitrary pages of long documents, testing file integrity, or just for fun. Every pick uses cryptographically secure randomness by default.

Unlike most online tools, BigToolz runs 100% in your browser using pdf-lib. Your PDFs never uploaded to any server complete privacy, instant results, no file size limits.

🎯 Two Modes Explained

📚 Multiple Pages

Pick N unique random pages (default 3). Perfect for random sampling, quizzes, or spot-checking long documents. Each page is picked at most once.

🎯 Single Page

Pick 1 random page. Simple and quick useful when you just want to sample one page without thinking about count.

🔐 Reproducible Randomness with Seeds

By default, every pick uses crypto.getRandomValues() cryptographically secure, unpredictable randomness. Each "Pick" and "Re-roll" produces a different result.

If you want reproducible results (e.g., for tests, shared challenges, or research), enter a seed any text or number. The same seed with the same PDF will always produce the same picks. This is useful for:

  • Sharing a random selection with a friend send them the same seed.
  • Running reproducible experiments same PDF + seed = same output.
  • Testing tools deterministic results across runs.
